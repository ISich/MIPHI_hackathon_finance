# Manrope

Variable Manrope, normal style, weights 400–700. Latin and Cyrillic subsets are served locally; no external font service is used at runtime.

Source: [Google Fonts CSS API](https://fonts.googleapis.com/css2?family=Manrope:wght@400..700&display=swap), Manrope v23, retrieved 2026-11-07.

- Cyrillic: `https://fonts.gstatic.com/s/manrope/v23/xn7gYHE41ni1AdIRggOxSvfedN62Zw.woff2`
- Latin: `https://fonts.gstatic.com/s/manrope/v23/xn7gYHE41ni1AdIRggexSvfedN4.woff2`
