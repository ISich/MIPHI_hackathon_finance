## Устаревшее в TEAM_AGENT_HANDOFF.md

`TEAM_AGENT_HANDOFF.md` получен отдельным вложением вне этого репозитория; используется как контекст, не включён в пакет и не новая норма: PRD уже 0.3, не 0.2; код выбирается на слот, не обязательно одним источником на весь Run; comparison view нужен checks, не только UI; планки относятся к приведению/сравнению, не всему pipeline; третий array mode scalar-value тоже нужен. AI необязательность организаторами не подтверждена, но команда уже явно отложила интеграцию до конца.

Роли A/B/C/D handoff — предложение. Мы предлагаем объединить A+B как D1 и разделить перегруженный C между D2 и D4; D из handoff соответствует D3 по UI. Для backend multiuser отвечает D2, для UI — D3: это не функция одного frontend.

## Изменение решения

Новый ADR/запись содержит ID, принятое решение, автора-человека, альтернативы, затронутые contracts/FR и дату фактического принятия. Не подменять согласование молчаливым изменением DTO. CI/branch protection/канбан могут менять только с разрешением владельца; отсутствие read:project не препятствует подготовке файлов docs.
