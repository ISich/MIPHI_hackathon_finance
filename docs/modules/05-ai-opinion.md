## Что уже решено

Пользователь выбрал планируемое подключение к имеющемуся на его стенде Codex-шлюзу через `/v1`, затем отложил его до конца. OpenRouter/DeepSeek были предыдущей рекомендацией, не активной конфигурацией. Наличие/доступность gateway, model ID, протокол и условия аккаунта не проверены. Сейчас параметры подключения/секреты не запрашиваются, запросы к модели и deployment не выполняются.

Командный порядок работ не подтверждает формальную необязательность AI у организаторов: это по-прежнему Q1 исходного PRD. Core полностью независим от модели; до подключения UI честно показывает отсутствие AI-мнения, не синтетическую заглушку.

## Владелец и вход/выход

D4: подготовка безопасного пакета и API client/валидация ответа; D2: server config, secrets, выполнение задачи; D3: секция в том же check-report и экспорт. Backend → закрытый gateway → модель. Никаких Codex tools/файловых/командных полномочий из содержимого отчёта.

Вход: готовый report snapshot, обезличенные агрегаты, top изменённых PATH, результаты checks, ограниченные примеры различий. Не весь datamart и не сырые персональные JSON. Выход — отдельно обозначенное мнение: summary, findings со ссылками только на переданные факты, limitations. Не менять counts, PASS/FAIL и CONFIDENCE исходных checks; корреляция не объявляется доказанной причиной.

## Поздняя интеграция

После готового и проверенного ядра уточнить base URL/model ID/протокол без запроса токенов в чате. `/v1` сам не говорит, это Responses или Chat Completions. Codex CLI с OAuth-входом сам по себе не является общим HTTP API. Если backend в контейнере, localhost — не адрес хоста. Не копировать auth.json в web-приложение/runner.

Секреты только у backend, конечный timeout/output budget, ограниченные повторы, кэш по snapshot+model+prompt revision. Нет сети/модели — явная ошибка AI без отказа готового отчёта. Готовое мнение или статус на момент выгрузки попадает в HTML по принятому дизайну; ссылки и текст экранируются.

## AC-21 — только после core

Реальный обезличенный snapshot → валидный ответ со ссылками; проверить отсутствие выдуманных чисел, стоимость/лимиты и длительность на фактическом маршруте; negative tests timeout/invalid JSON/неизвестные references. До реального теста не писать «подключено», «бесплатно» или «качество проверено».
