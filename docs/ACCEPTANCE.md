### Подготовка локального стенда к записи

```bash
cd backend
DD_EXECUTION_MODE=trusted-local \
DD_DATA_ROOTS=examples=.core/$(cat CORE_COMMIT)/examples,data=/путь/к/data \
DD_REPORT_UI_BASE=http://127.0.0.1:5173 \
.venv/bin/python -m dd_backend serve --host 127.0.0.1 --port 8000

.venv/bin/python -m dd_backend register-dataset --name "RUN-20260827-0001" --root data --mode dirs \
    --before RUN-20260827-0001/RESULTS/BEFORE_MASTER --after RUN-20260827-0001/RESULTS/AFTER_BETA

cd ../frontend && DD_API_TARGET=http://127.0.0.1:8000 npm run dev
```

Вход в UI: локально `admin` / `admin12345`. Учётная запись создаётся при старте API, её можно переопределить через `DD_AUTH_USERNAME` и `DD_AUTH_PASSWORD` (см. `backend/README.md`, «Account sign-in»).
